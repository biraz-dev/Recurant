# Provenance and use

New material sources were generated with the built-in image generation tool from original surface briefs. Runtime PNGs were derived by permitted exact cropping and resizing, with the explicitly requested one-bit theme additionally using binary threshold conversion; individual workers record any image-generator seam revision. No script-painted replacement art or fabricated PBR data is supplied. Public prompt text uses normalized generic theme names; internal generation/transfer identifiers are deliberately omitted. Source artwork pixels are unchanged. QA renders are produced from actual geometry in Blender, not image-generated mockups. The one-bit actual-render previews additionally use geometry-derived black contours and an ordered two-color Bayer conversion for strict binary readability; these are explicitly documented presentation operations, not replacement artwork.

New mesh shapes are original local parametric construction: masonry, circulation, timber, organic roots/rocks/foliage, crystal, machinery, textiles, props, landscape and infrastructure. Editable source is included. No third-party mesh assets or external download dependencies are required for the new kits.
